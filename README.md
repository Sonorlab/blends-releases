# BLENDS — downloads

Official downloads for **BLENDS**, a granular synthesizer plugin by
[Sonorlab](https://sonorlab.com).

Grab the latest build for your platform on the
**[Releases](../../releases/latest)** page:

| Platform | File | Includes |
|----------|------|----------|
| Windows  | `BLENDS-Windows.zip`  | VST3 + standalone app |
| macOS    | `BLENDS-macOS.dmg`    | VST3 / AU |
| Linux    | `BLENDS-Linux.tar.gz` | VST3 + standalone app |

Every build includes a **free 20-minute trial**. Buy a license at
[sonorlab.com](https://sonorlab.com) to unlock it permanently — your key works on
all your machines and all future updates.
